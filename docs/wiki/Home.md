# Flux Pylons

Power nearby machines without cables or a receiver block attached to each one. Feed a Flux Pylon from a generator or energy cell, then use the Flux Gadget to link the machines around it.

![A Flux Pylon and the handheld gadget](https://raw.githubusercontent.com/shikyo13/Flux-Pylons/main/docs/images/pylon-and-gadget.png)

Download the mod from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/flux-pylons). Version 1.2.0 supports **Minecraft 1.21.1 on NeoForge** and **Minecraft 1.20.1 on Forge**. Choose the matching file and install it on both the server and clients. Flux Pylons needs an energy source from another mod.
